# So too either neither as well also

| Expression  | Sentence Type | Position               | Sentence Structure                                                      | Example                                              |
| ----------- | ------------- | ---------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------- |
| **Too**     | Positive      | End                    | Subject + verb + object + **too**                                       | I like tea **too**.                                  |
| **As well** | Positive      | End                    | Subject + verb + object + **as well**                                   | I like tea **as well**.                              |
| **Also**    | Positive      | Before verb / start    | **Also**, subject + verb + object<br>Subject + **also** + verb + object | She **also** likes tea. <br>**Also**, I like coffee. |
| **Either**  | Negative      | End                    | Subject + negative verb + object + **either**                           | I don’t like tea **either**.                         |
| **Neither,Nor** | Negative      | Start + verb inversion | **Neither** + auxiliary/modal + subject                                 | I don’t like tea. **Neither do I**.                  |
| **So**      | Positive      | Start + verb inversion | **So** + auxiliary/modal + subject                                      | I like tea. **So do I**.                             |


- As well and too are similar.`as well` is just a bit formal.
- `They sleep eight hours a day` => `We do too` => `We do as well.` => `We sleep eight hours too` => `so do we` => `we also sleep eight hours a day`
- `Maria isn't as honest as you think.` => `Julia isn't either.` => `Neither is Julia.`
- **me too**: Used to agree with a positive statement without repeating the full sentence. `I will go to my hometown this holiday. → Me too.`
- **me neither**: Used to agree with a negative sentence without repeating the full sentence. `I don’t like that movie. → Me neither.`
- In speaking and  writing, we can place "too" after the subject to sound a bit more formal or emphatic. `  
     - `His brother owes me 20 dollars.` => `He, too, owes me 10 dollars.`
- ‘Too’ works in short answers; ‘also’ is used only in full sentences.
- **Just as + [clause 1], so + [clause 2].**: in the same way that [clause 1] happens, [clause 2] happens.
    - `Just as the caterpillar becomes a butterfly, so we grow and change.`
    - `Just as a poet starts with a blank page, so engineers begin with an empty file.`
